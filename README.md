# 叶朗《中国美学史大纲》考研笔记 Skill
> 豆包外置Skill｜面向美学、美术史论考研。严格忠于叶朗教材原文，输出章节考情、重难点、考研题库、学术思维导图、跨章节专题迁移，支持生成Word结构化笔记、讲课PPT完整授课大纲。

## ✨项目特点
1. **忠实原著**：80%表述沿用叶朗《中国美学史大纲》原文，减少AI改写；课外拓展内容会明确标注。
2. **考研导向**：对标国内多所高校美学真题，划分高频/中频/低频考点；名词解释、简答、论述完全适配考研阅卷答题范式。
3. **消除AI痕迹**：思维导图使用纯文本缩进，无花哨代码块、无多余emoji，模拟人手整理笔记，可直接导入幕布/XMind/Obsidian。
4. **核心增值模块：专题迁移整合**
    - 历史线索：梳理本章在整部教材的承上启下；提供大题答题线索。
    - 专题研究：拆分简答小专题 + 论述压轴大专题，解决考研跨章节综合题难点。
5. **双输出能力**
    - 输出可复制到Word的Markdown结构化笔记，可导出PDF备考。
    - 输出完整逐页讲课PPT大纲，用于考研授课、读书汇报。

## 📂仓库文件说明
- `skill.yaml` Skill配置文件（导入外置Skill时选择该文件）
- `skill.md` Skill核心系统提示词
- `README.md` 本说明文档

## 🛠️安装方法（豆包电脑客户端）
1. 将本仓库Clone/Download到本地。
2. 打开豆包PC客户端 → Skill → 导入外置Skill。
3. 选中 `skill.yaml`，完成导入。
4. 启用该Skill，直接输入指令使用。

## 💡使用示例
>示例1（基础章节输出）
`叶朗中国美学史大纲 第一章老子的美学`

>示例2（输出Word可用笔记）
`叶朗中国美学史大纲 第一章老子的美学，生成word版笔记`

>示例3（输出讲课PPT）
`叶朗中国美学史大纲 第一章老子的美学，生成本章讲课PPT完整大纲`

>示例4（指定专题）
`叶朗中国美学史大纲，梳理审美心胸理论专题`

## 📄输出用途
1. 复制Markdown粘贴Word，制作自己的考研PDF笔记。
2. 思维导图文本复制进XMind、幕布生成脑图，辅助背诵。
3. PPT大纲直接用于备课、线上线下考研讲课、读书汇报。

## ⚠️重要提示
1. 所有答题素材以叶朗原书为基准，拓展内容仅作补充，考场优先使用教材原文。
2. 哲学类美学命题答题务必区分**哲学本义**与**美学史转化结果**，是阅卷重要得分点。
3. 版本考据（帛书本、通行本等）一般作为背景，考研答题不建议大段展开。
